Kantorovich schemes and parallel running symbolic transformations

Many operations in computer algebra systems can be separated for parallel running. For example, when a sum is integrated, the first thing to do is to integrate each term separately.

It is important to have a possibility to represent the expression in a form not only suitable for performing efficient transformations, but also for parallel performing.

Returning to expression representation from Section 2 we can see after careful examination that first steps may be performed in parallel. 

  Step 1.    T1 = v*w,    T2 = v**2,   T4 = cos(v)
  Step 2.    T5 = 2*T4,   T3 = T1+T2
  Step 3.    T7 = T3+9,   T6 = T5+7
  Step 4.    EXP = T7*T6

It is possible to carry out analysis of independence of the scheme strings, because a string of scheme includes reference to another scheme string.

The following analysis algorithm can be used. Let an expression be represented in SK form. Each string contains linking operand pointing at a scheme string number.

Let S1, S2,..., SN be sets of strings performed in parallel. First of all, the strings not containing numbers of another string are considered. Such strings may be performed in parallel, and after their separation one can pass to considering of other strings.

Let's consider the remaining strings in set U. By means of linking operand analysis, strings sets performed concurrently are formed. The sets of strings performed in parallel contain the strings of scheme, operands of which being the strings performed in parallel on previous steps.

Such concurrently performed string sets should be performed consequently until set U is empty.

Formation of concurrently performed sets can be used for construction of algebraic programs performed in parallel.

To summarize, the KS can be very useful for parallel running of symbol transformations.
