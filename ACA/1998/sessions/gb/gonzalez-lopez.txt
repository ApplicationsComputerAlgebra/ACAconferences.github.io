In this paper it is shown how to deal with polynomial system solving
involving
parameters by using the Hilbert function in order to check that the
specialization of a ``generic" Gr\"obner Basis of the parametric polynomial
system (computed in a polynomial ring containing the parameters and the
unknowns as variables) is a Gr\"obner Basis of the specialized polynomial
system. A preliminary implementation of these algorithms into the PoSSoLib is
also reported.
