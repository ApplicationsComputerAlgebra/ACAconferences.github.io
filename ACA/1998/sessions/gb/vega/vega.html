Abstract:

In this paper it is shown how to deal with homogeneous polynomial system solving involving parameters by using the Hilbert function in order to check that the specialization of a ``generic" Gröbner Basis of the parametric homogeneous polynomial system (computed in a polynomial ring containing the parameters and the unknowns as variables) is a Gröbner Basis of the specialized homogeneous polynomial system. A preliminary implementation of these algorithms into the PoSSoLib is also reported.
