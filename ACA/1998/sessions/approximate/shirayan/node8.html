Moore-Penrose generalized inverses

Given an #tex2html_wrap_inline1435# matrix A with entries in the reals, an #tex2html_wrap_inline1439# matrix G is said to be the Moore-Penrose generalized inverse of A, or for short MPG-inverse of A, if G satisfies the following four conditions:
<#3108#>(i)<#3108#>
AGA=A
<#3109#>(ii)<#3109#>
GAG=G
<#3110#>(iii)<#3110#>
(AG)T=AG
<#3111#>(iv)<#3111#>
(GA)T=GA
where BT denotes the transpose of B. G is uniquely determined by A and often written as A+.

Moore-Penrose generalized inverses are an important tool for solving a system of linear equations #math83##tex2html_wrap_inline1471#. When there is no strict solution, it is possible to find the <#413#>least square solution<#413#> by #math84##tex2html_wrap_inline1477#, where #math85##tex2html_wrap_inline1483# is minimal with #math86##tex2html_wrap_inline1487# minimal. The norm #tex2html_wrap_inline1489# is the Euclidean norm, i.e. the square root of the sum of squares of each component. For the details see [#RM##1###]. Moreover, MPG-inverses are applied to engineering such as associative memory and pattern recognition, see [#therrien##1###].
