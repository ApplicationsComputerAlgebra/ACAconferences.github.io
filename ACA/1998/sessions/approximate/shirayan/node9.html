  • <#468#>Q.<#468#> The stabilization methodology guarantees that the result will converge to the true result as the precision increases. Does this happen in a manner similar to Newton's method?

One inputs an approximate solution and, when all goes well, Newton's method outputs a better approximate solution and the successive approximations converge to an exact solution. Using Newton's method one obtains a convergent sequence of results by using the output from one pass as the input to the next pass. In general #tex2html_wrap_inline1563# is not a successive approximation method and it would not be possible to use the output from one iteration of #tex2html_wrap_inline1565# as the input for the next iteration.11 By contrast an oversimplified description of #tex2html_wrap_inline1567# goes as follows:
    • When #tex2html_wrap_inline1569# is executed with (exact) input and exact computation a particular ``execution path'' through the algorithm occurs, based upon the specific program branching resulting from predicate evaluation.     Of course when we say ``increasingly accurate'' we mean ``increasingly accurate and convergent to the exact value.''
