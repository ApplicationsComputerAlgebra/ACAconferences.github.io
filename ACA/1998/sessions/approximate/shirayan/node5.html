Counting real roots

Sturm's algorithm is an algorithm to count the number of all real roots of a given polynomial in one variable. Like Buchberger's algorithm, Sturm's algorithm also has the problem of intermediate expression swell in the size of the coefficients. There have been many efforts for improving the algorithm like the Sturm-Habicht sequence as found in [#GLRR##1###]. But in the case where the coefficients are irrational, the above problem is still serious. What if we use floating-point computation without the methodology in [#SS##1###]? Sturm's algorithm is then also unstable.

We applied the stabilization techniques to Sturm's algorithm based on floating-point computation. In many cases, the greatest advantage was found for polynomials having irrational coefficients and multiple real roots9 . Namely, while a naive floating-point computation method could not give the correct number (the result varies or oscillates with the precision), our methodology stabilized and could give the correct number for a relatively low precision.
