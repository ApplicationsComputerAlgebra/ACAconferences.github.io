The numeric part receives Eq. (2) and (3), and computes numerical solutions to it. Let R be a region defined by Eq. (2) and (3) and be an objective function which has the minimum point in -space.

First of all, it is checked whether sub-region Rij consists of a finite number of points. If it does, the numerical solutions are computed. Otherwise, singular point loci of Rij and stationary point loci of the objective function are computed. In the stationary point computation, a list of objective functions which have been already used is made in order to avoid applying the same function in the recursive computation. Then, it is checked whether each obtained locus have a finite number of points. The computation is recursively executed until there exist a finite number of solutions.
