Symbolic part

The symbolic part conducts the following computations by constructing a reduction tree.
1.
Finding out inequalities which cannot be satisfied simultaneously
2.
Obtaining a set of inequalities which can be replaced by a set of equations
Furthermore, the symbolic part detects design variables whose values should be changed in order to remove inconsistency. Because, in embodiment design, it is quite important for a designer to know what variable values are not appropriate.

Section 2.4.1 explains the computation using a reduction tree. After that, in Section 2.4.2, the method of detecting design variables whose values should be changed is described.
