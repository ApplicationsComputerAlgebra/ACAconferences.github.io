Applications of Quantifier Elimination Software to Control System Design: An Overview

Peter Dorato
Department of Electrical and Computer Engineering
University of New Mexico
Albuquerque, NM 87131-1356, USA
{peter}@eece.unm.edu

ABSTRACT
In this paper we present an overview of applications of QEPCAD software to various control system design problems, including applications to:
  • Robust Stabilization
  • Robust Multi-Objective Design
  • Nonlinear System Design
  • Non-Fragile Compensator Design
  • Gain and Phase Margin Design
In addition papers presented in this session on control system design via symbolic quantifier elimination will be summarized.
