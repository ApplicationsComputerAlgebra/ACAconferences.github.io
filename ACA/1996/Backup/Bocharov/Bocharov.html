Variations on the Theme of Thomas-Rosenfeld with the New Version of Mathematica

Alexei V. Bocharov, Evgenii M. Vorob'ev

Date: July 20th (Saturday)
Time: 09:00-09:30
Abstract
An implementation of a new algorithm of Thomas-Rosenfeld type for reduction of overdetermined systems of differential equations is described. The implementation is based on new features of Mathematica Groebner code as well as on some old and new optimization ideas.
