\begin{center}
\large
Abstract
\end{center}

An implementation of a new algorithm of Thomas-Rosenfeld type for reduction of
overdetermined systems of differential equations is described. The implementation is based on
new features of Mathematica Groebner code as well as on some old and new optimization ideas.
