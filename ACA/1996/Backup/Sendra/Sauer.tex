\begin{center}
\large
Abstract
\end{center}

The talk is concerned with an algorithm to find a minimal Groebner basis for an ideal which is
given as the joint kernel of linearly independent linear functionals - the generic example is
Lagrange interpolation at a finite set of pairwise distinct points. The method results from
constructing a particular polynomial subspace which admits unqiue interpolation and satisfies
certain other constraints.
